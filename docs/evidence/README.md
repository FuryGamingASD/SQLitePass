# Synthetic benchmark evidence

The benchmark JSON files were generated by the project's harness using synthetic vaults and non-production credentials. Their protocol, runtime, measured fields and limitations are documented in [PERFORMANCE_2026-11-16.md](../PERFORMANCE_2026-11-16.md).

The [1.1.3 verification summary](release-readiness-1.1.3.json) preserves results collected before publication. The local hidden WPF rerun passed all 1,080 layout cases. The earlier partial render had no final manifest or exception trace, and the reported crash remains unreproduced. Detailed local TRX reports, render images and raw output remain under ignored `artifacts/verification/` directories.

The published build passed 162 tests, 1,080 layout cases and four Windows package scenarios. The [release outcome](../releases/RELEASE_OUTCOME_1.1.3.md) records the CI run, public asset digests, Velopack feed verification and the partial Windows VM checklist.

The numbers are local observations of managed heap retention/allocations and elapsed time. They are not total process memory, statistical averages, worst-case latencies, native UI measurements or proof of performance on another device. Every query still authenticates and scans the vault; the evidence must not be presented as eliminating O(N) work.
