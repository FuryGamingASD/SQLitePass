# Synthetic benchmark evidence

The benchmark JSON files were generated by the project's harness using synthetic vaults and non-production credentials. Their protocol, runtime, measured fields and limitations are documented in [PERFORMANCE_2026-11-16.md](../PERFORMANCE_2026-11-16.md).

The [1.1.3 local verification summary](release-readiness-1.1.3.json) records a locked Release build with the pinned SDK, 161 passing automated tests, zero known NuGet advisories and a passing session-only synthetic check. The completed pre-fix full hidden WPF render failed during cleanup of a synthetic dirty editor; the post-fix full render was interrupted after the user reported an application crash and has no result. Native Windows checklist items were not run. Detailed TRX, render images and raw verifier output remain local under the ignored `artifacts/verification/1.1.3-readiness/` directory.

The numbers are local observations of managed heap retention/allocations and elapsed time. They are not total process memory, statistical averages, worst-case latencies, native UI measurements or proof of performance on another device. Every query still authenticates and scans the vault; the evidence must not be presented as eliminating O(N) work.
