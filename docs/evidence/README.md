# Synthetic benchmark evidence

The benchmark JSON files were generated by the project's harness using synthetic vaults and non-production credentials. Their protocol, runtime, measured fields and limitations are documented in [PERFORMANCE_2026-11-16.md](../PERFORMANCE_2026-11-16.md).

The [1.1.3 verification summary](release-readiness-1.1.3.json) records local Release build, test and dependency-scan results plus hosted PR CI run #112 on the current PR head. Hosted CI passed 161 tests, all 1,080 hidden WPF cases, 105 contrast pairs, package checks, and temporary-directory install/upgrade/uninstall smoke checks. It did not launch the app or open a real vault. CI artifacts expire after 14 days and do not represent a publication. The local post-fix full render was interrupted when the user reported an app crash; no local result was obtained and causality is unknown. Native Windows checklist items were not run. Detailed local TRX, render images and raw verifier output remain under the ignored `artifacts/verification/1.1.3-readiness/` directory.

The numbers are local observations of managed heap retention/allocations and elapsed time. They are not total process memory, statistical averages, worst-case latencies, native UI measurements or proof of performance on another device. Every query still authenticates and scans the vault; the evidence must not be presented as eliminating O(N) work.
